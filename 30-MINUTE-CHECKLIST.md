# 30-Minute Checklist

### 0–5 minutes
Open the folder in VS Code and check `index.html` in your browser.

Change anything you want, especially your university name/program if you want to include it.

### 5–10 minutes
Test:
- About
- Education
- Skills
- Contact
- GitHub link
- LinkedIn link
- Mobile view

### 10–18 minutes — GitHub
Create a public repository called `portfolio`.

Upload:
- `index.html`
- `style.css`
- `README.md`
- the supporting `.md` and `.txt` files

Or use Git:
```bash
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/abdulrehmanyaseen0316-prog/portfolio.git
git push -u origin main
```

### 18–24 minutes — Vercel
Connect/import the GitHub repository into Vercel and deploy it.

Copy your generated `vercel.app` URL.

### 24–28 minutes — LinkedIn
Open `LINKEDIN-POST.txt`, put your hosted URL into the post, publish it, and copy the post URL.

### 28–30 minutes — Evidence
Take screenshots of:
1. LinkedIn post
2. GitHub repository
3. Live website

Submit:
- LinkedIn post URL
- LinkedIn screenshot
- GitHub URL
- hosted website URL

### Domain
A custom domain is optional. With only 30 minutes, use the Vercel URL first unless your teacher specifically requires a purchased domain.
